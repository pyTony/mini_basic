HTML handbook. Open this file from the clone root. Pages live under docs/site/.

Regular 1.00 is text and console. Version 1.0.0.dev0 until tagged. Markdown sources stay next to these pages; this file is the browser front door.

Start with Install to run programs. Use Public tree for every user-facing path.

Run

pip install "mini-basic[repl] @ git+https://github.com/pyTony/mini_basic.git"
mini-basic --version
python -m mini_basic

Examples and this handbook are in the git checkout, not the pip wheel.
