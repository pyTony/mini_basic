Public tree

Paths that ship on GitHub. This is not a map of local developer extras.

After git clone https://github.com/pyTony/mini_basic.git you have the layout below. A plain pip install from GitHub only puts the mini_basic/ package on sys.path.

Not in this tree

Agent status files, work logs, approval lists, resource probes, and local utils/*.py helpers stay on the developer machine. They are gitignored on purpose so a GitHub clone stays a product repo.
