Public tree

Paths that ship on GitHub. This is not a map of local developer extras.

After git clone https://github.com/pyTony/mini_basic.git (the main branch) you have the lean release layout below. A plain pip install from GitHub only puts the mini_basic/ package on sys.path. The full development tree (examples/, test/, tools/, scripts/, utils/, documentation/) lives on the dev branch instead — see its own tree there.
