mini_basic

Multi-dialect BASIC interpreter. Regular 1.00 is text and console. Version 1.0.0.dev0 until tagged.

This is the browsable handbook for the public project: what you get from GitHub, how to install it with pip, and what each folder is for. From the clone root, open index.html. Local agent/status files are not part of this product and are not documented here.

Start with Install if you want to run programs. Use Public tree to see every user-facing path.

Run

pip install "mini-basic[repl] @ git+https://github.com/pyTony/mini_basic.git"
mini-basic --version
python -m mini_basic

Examples and this handbook live in the git checkout, not in the pip wheel. Clone the repo (or use an editable install) to run examples/.

Dialects

NameRole
miniDefault superset (numbered + unnumbered)
bbcBBCSDL / BB4W-oriented language
