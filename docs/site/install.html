Install

pip from GitHub installs the interpreter. Clone the repo to get examples and this handbook.

1. Interpreter only (pip from GitHub)

Requires Python 3.10+. This is the supported “just run BASIC” path. It does not copy examples/ or docs/ into site-packages.

python -m pip install -U pip
python -m pip install "mini-basic @ git+https://github.com/pyTony/mini_basic.git"
mini-basic --version
python -m mini_basic --help

Optional extras:

python -m pip install "mini-basic[repl] @ git+https://github.com/pyTony/mini_basic.git"
python -m pip install "mini-basic[display] @ git+https://github.com/pyTony/mini_basic.git"
python -m pip install "mini-basic[all] @ git+https://github.com/pyTony/mini_basic.git"
ExtraAddsRegular 1.00?
replpyreadline3 on Windows (line editing)Nice to have
displaypygame-ce for MODE / PLOT windowsNo — optional flavor
allBoth—

Console scripts after install: mini-basic, minibasic, mini_basic.

python -m mini_basic -c "PRINT 6*7"

If -c is not available in your build, start the REPL and type PRINT 6*7.

2. Full public tree (clone + pip)

Use this when you want examples, tests, and these HTML pages.

git clone https://github.com/pyTony/mini_basic.git
cd mini_basic
python -m pip install -e ".[repl]"
python -m mini_basic examples/mini/hello_args.bas hello
python -m mini_basic --dialect mits examples/m6502-cport/01_hello.bas
python -m pytest -q -m "phase1 and not slow" --timeout=45

Open the handbook in a browser from the checkout root:

index.html

The rest of the pages are under docs/site/ (same site).

What pip does not install

  • examples/, basics/ — run from a clone
  • test/, scripts/, tools/ — development

See PACKAGING for the wheel contents.
