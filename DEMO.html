Showcase demo reel

Eight confirmed-working programs picked to span graphics, fractals, performance and language features. They live under showcase/ and run via showcase/demo_reel.py:

python showcase/demo_reel.py          # run the whole reel, in order
python showcase/demo_reel.py --list   # just print what's in it
python showcase/demo_reel.py wheel fern   # run just these entries

Pygame entries open a window (close it, or press the program's usual exit key, to move to the next one). The console entry (mandel_ansi) just prints and returns.

The reel

Run one directly (without the launcher)

python -m mini_basic --pygame --dialect bbc showcase/disco.bbc
python -m mini_basic --dialect mini showcase/Mandel_ANSI.BAS
